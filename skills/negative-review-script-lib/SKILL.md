# 差评应对话术库

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_02_sk03` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 口碑捍卫者 |
| 能力族 | 文本生成型 · 补救话术 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 中（私域复购管家复用安抚话术） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

按**根因分类树**（物流 / 质量 / 期望差 / 服务 / 价格 五类，多重命中取「质量 > 服务 > 物流 > 期望差 > 价格」最重者）匹配补救话术，按**补偿梯度**（<50 元补 5-10 元券；50-200 元补订单额 10%-20%；>200 元专人对接 + 电话）给方案。公开回复强制四要素结构（致歉 + 复述具体问题 + 已采取的措施 + 离线沟通渠道），60-120 字，服务「2 小时黄金响应窗口、差评回复率 100%」的运营目标。命中升级信号（12315 / 媒体曝光 / 律师函 / 集体投诉）自动停止套模板、输出人工处置清单。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `reviews` | string | ✅ | 差评原文（含星级、关键词、菜品/环节细节） |
| `root_cause` | string | ⬜ | 已判定的根因标签；缺省由本技能按分类树判定 |
| `policy` | string | ⬜ | 可用的补偿方式与授权上限（如「券最高 20 元」） |
| `order_amount` | number | ⬜ | 订单实付金额（元），决定补偿梯度档位 |

## 输出规格

- `replies`：逐条差评的话术方案（根因 / 命中依据 / 公开回复 / 私信话术 / 补偿方案 / 是否需人工确认）
- `root_cause`：归因结果与原话依据
- `recovery`：可执行补救动作清单，涉及补偿标注需人工确认
- `escalation`：升级预警清单（触发信号 + 建议动作），无则为空

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 提供差评原文 + 订单金额 + 补偿授权
4. 得到四要素结构的公开回复与梯度内补偿方案

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 不生成「返现换好评」「送菜删差评」及任何变体 —— 诱导删改差评违反平台评价规范与《反不正当竞争法》
- ❌ 不在公开区承诺退款金额，退款动作走私信或电话
- ❌ 不编造整改动作 —— 措施必须用户已确认发生过
- ❌ 不对疑似恶意差评写反击话术，只输出申诉材料要点
- ❌ 不替店主拍板超授权补偿，>200 元订单只出对接建议

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "reviews": "分量越来越少了，一份牛肉面就三片牛肉，价格还涨了，不会再来了",
  "root_cause": "",
  "policy": "可发优惠券，单张最高 15 元",
  "order_amount": 26
}
```

**输出**（要点）：

| # | 根因 | 命中依据 | 公开回复（节选） | 补偿方案 |
|---|---|---|---|---|
| 1 | 价格（叠加质量疑虑） | 「三片牛肉」「价格还涨」 | 致歉 + 复述「三片牛肉」+ 说明出餐克重已恢复标准 150g + 留店长私信 | 10 元券（<50 元档，未超 15 元授权） |

需人工确认：出餐克重整改动作是否已执行；确认后方可发布。
