# 使用示例

以下示例的输入均为**真实可跑数据**，输出由模型按 `prompt.txt` 的三类红线方法论生成。

---

## 示例 1：私信话术（诱导删改评价 + 超授权）

**输入**：`examples/input.json`（2 条私信，授权上限 15 元）

**输出**：红线 1（「把那条评价改一下」→ 诱导删改评价）/ 警告 1（「下次来一定不一样」
→ 过度承诺）/ 提示 1（补 20 元超 15 元授权）。整体判定**退回重写**。
整改后话术：「本单我们承担 15 元退款（已按授权办理），欢迎您再给一次机会。」

---

## 示例 2：公开回复（对照组，判定通过）

**输入**：

```json
{
  "text": "您好，看到您反馈的出餐慢问题，很抱歉。门店已增加高峰期双人出餐，欢迎您私信店长，欢迎再给一次机会。",
  "platform": "美团",
  "policy": "无补偿授权"
}
```

**输出**：0 红线 0 警告，判定**通过**。「欢迎再给一次机会」属合规表述不误报；
四要素齐全且无绝对化用语。

---

## 示例 3：隐私泄露（红线拦截）

**输入**：

```json
{
  "text": "王女士（尾号 6721）您的过敏史我们已记录，桌号 8 的订单金额 268 元已退",
  "platform": "点评"
}
```

**输出**：红线 1 —— 公开回复暴露姓氏 + 手机尾号 + 桌号 + 消费金额，命中
《个人信息保护法》脱敏要求，平台脱敏检测会直接驳回。改法：「该客户的退款已在
24 小时内处理完毕」（不出现任何可识别信息），整体判定**退回重写**。

---

*输出为 AI 生成内容，不构成法律意见；发布前须经店主确认。*
